# RGNMR patch

Our changes to [RGNMR](https://github.com/eilon96/RGNMR), commit `66dfb8c`. Clone RGNMR into `lib/Baselines/RGNMR` (see the main README). We use the settings of the authors' `RGNMR_DEMO.m` (`max_outer_iter = 50`, `stop_relRes = 1e-15`) and give RGNMR the rank and the number of corrupted entries.
